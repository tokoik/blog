## `dvipdfmx` のエラー

[fink](http://www.finkproject.org/index.php?phpLang=ja) の `dvipdfmx` で日本語を含む `dvi` ファイルを変換しようとすると，エラーになってしまいます．

```cpp
% dvipdfmx test.dvi

test.dvi -> test.pdf

[1
** ERROR ** Could not find encoding file: H

Output file removed.
```

## CMap ファイルをコピー

ftp://ftp.oreilly.com/pub/examples/nutshell/cjkv/adobe/aj16.tar.Z をダウンロードして CMap ディレクトリを/sw/share/texmf/dvipdfm の下に置き，

```cpp
% sudo mktexlsr
```

したら通るようになりました．
