## Unity のメッシュ

### *メディアデザインセミナー 2B**

和歌山大学 システム工学部 / 床井浩平

Unity におけるプロシージャルメッシュ（スクリプトによる動的メッシュ生成）、頂点アトリビュート（位置・法線・UV座標）と頂点インデックスの扱い、マテリアルとシェーダ（Surface Shader）、およびコンピュータグラフィックスにおける立体形状表現の基礎理論についての講義資料です。

## スライド 5: 図形は頂点アトリビュートと頂点インデックスで表される

**頂点アトリビュート (Vertex Attributes)**
: 位置や法線など、個々の頂点が持つデータ（頂点属性）。

**頂点インデックス (Vertex Indices)**
: 三角形を構成する頂点の番号の組み合わせ。

| 三角形 | A | | | B | | | C | | |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **頂点番号** | ⓪ | ③ | ① | ① | ③ | ② | ③ | ⑤ | ④ |

![頂点アトリビュートとインデックス]({{ site.baseurl }}/assets/images/mesh/image4.png)

## スライド 51: 頂点の位置と法線を求める

円周に沿って各頂点の位置と法線をループで求めます。

```csharp
        // 各頂点の位置と法線を求める
        for (int i = 0; i <= slices; ++i)
        {
            // 頂点の位置の角度
            float theta = dtheta * i;

            // 頂点の位置の x, z 座標値
            float x = radius * Mathf.Cos(theta);
            float z = radius * Mathf.Sin(theta);

            // 頂点の法線ベクトル
            Vector3 normal = new Vector3(x, 0f, z).normalized;

            // 下段の頂点 (2 * i)
            myVertices[2 * i].Set(x, -height * 0.5f, z);
            myNormals[2 * i] = normal;

            // 上段の頂点 (2 * i + 1)
            myVertices[2 * i + 1].Set(x, height * 0.5f, z);
            myNormals[2 * i + 1] = normal;
        }
```

## スライド 69: 解答例 (2) 頂点の緯度から高さ $y_j$ とその断面の半径 $r$ を求める

頂点の緯度から高さ $y_j$ とその断面の半径 $r_j$ を求めます。

$$v = \frac{j}{\text{stacks}}$$
$$\text{latitude} = \pi \times v$$
$$y_j = -\text{radius} \times \cos(\text{latitude})$$
$$r_j = \text{radius} \times \sin(\text{latitude})$$

```csharp
        // 各頂点の位置と法線を求める
        for (int j = 0; j <= stacks; ++j)
        {
            // 縦方向のパラメータ (0→1)
            float v = (float)j / stacks;

            // 各段の緯度 (南極が 0, 北極が π)
            float latitude = Mathf.PI * v;

            // 各段の高さ
            float yj = -radius * Mathf.Cos(latitude);

            // 各段の半径
            float rj = radius * Mathf.Sin(latitude);

            // 各段の左端の頂点番号
            int p0 = j * (slices + 1);
```

```csharp
            for (int i = 0; i <= slices; ++i)
            {
                // 横方向のパラメータ (0→1)
                float u = (float)i / slices;

                // 経度
                float longitude = 2f * Mathf.PI * u;

                // 頂点の x, z 座標値
                float xi = rj * Mathf.Cos(longitude);
                float zi = rj * Mathf.Sin(longitude);

                int pi = p0 + i;

                // 頂点位置の設定
                myVertices[pi].Set(xi, yj, zi);

                // 球面上の法線は中心からの位置ベクトルを正規化したもの
                myNormals[pi] = myVertices[pi].normalized;
            }
        }
        // (インデックス設定およびメッシュの割り当ては格子と同様)
```

$$\mathbf{M} = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$$
$$\mathbf{t}_{uv} = \mathbf{M} \mathbf{t}_{uv\_\text{MainTex}}$$

```hlsl
        void surf (Input IN, inout SurfaceOutputStandard o)
        {
            float cosTheta = cos(_Theta);
            float sinTheta = sin(_Theta);

            float2x2 m = float2x2(cosTheta, -sinTheta,
                                  sinTheta,  cosTheta);

            float2 uv = mul(m, IN.uv_MainTex);

            fixed4 c = tex2D (_MainTex, uv) * _Color;
            o.Albedo = c.rgb;
```

## スライド 121: テクスチャの中心を中心にして回転する

中心 $(0.5, 0.5)$ を中心とした回転を行列で記述します。

$$\mathbf{c} = \begin{pmatrix} 0.5 \\ 0.5 \end{pmatrix}$$
$$\mathbf{t}_{uv} = \mathbf{M}(\mathbf{t}_{uv\_\text{MainTex}} - \mathbf{c}) + \mathbf{c}$$

```hlsl
        void surf (Input IN, inout SurfaceOutputStandard o)
        {
            float cosTheta = cos(_Theta);
            float sinTheta = sin(_Theta);

            float2x2 m = float2x2(cosTheta, -sinTheta,
                                  sinTheta,  cosTheta);

            // 中心を引いて回転し、中心を足し戻す
            float2 uv = mul(m, IN.uv_MainTex - 0.5) + 0.5;

            fixed4 c = tex2D (_MainTex, uv) * _Color;
            o.Albedo = c.rgb;
```

## スライド 125: バーテックスシェーダで頂点の位置を変更する

バーテックスシェーダで頂点位置を変更する:

```hlsl
void vert (inout appdata_full v)
{
    float magnitude = length(v.vertex.xyz);
    float s = _Time.y * 20.0;
    float r = 0.2 * sin(s + magnitude * 2.0);

    // 法線方向に変位
    v.vertex.xyz += v.normal * r;
}
```

> バーテックスシェーダで頂点位置を変更した場合、隣接する頂点位置を参照できないため、通常の陰影計算では法線ベクトルが元のままとなり陰影が正しく更新されません。

## スライド 128: 法線ベクトルを解析的に求める

波面の陰関数表示から、勾配（グラディエント）を計算して解析的に法線ベクトルを求めます。

波面の関数:
$$f(x, y, z) = \sin(20t + 2\sqrt{x^2+y^2+z^2}) - (ax + by + cz) = 0$$

法線ベクトル（勾配の符号反転）:
$$\mathbf{n} = -\nabla f(x, y, z) = \begin{pmatrix} a - \frac{2x \cos(20t + 2\sqrt{x^2+y^2+z^2})}{\sqrt{x^2+y^2+z^2}} \\ b - \frac{2y \cos(20t + 2\sqrt{x^2+y^2+z^2})}{\sqrt{x^2+y^2+z^2}} \\ c - \frac{2z \cos(20t + 2\sqrt{x^2+y^2+z^2})}{\sqrt{x^2+y^2+z^2}} \end{pmatrix}$$

```hlsl
void vert (inout appdata_full v)
{
    float magnitude = length(v.vertex.xyz);
    float s = _Time.y * 20.0;
    float phase = s + magnitude * 2.0;

    // 頂点の変位
    v.vertex.xyz += v.normal * (0.2 * sin(phase));

    // 解析的に法線を計算
    float c = cos(phase);
    v.normal = normalize(v.normal - (2.0 * c / magnitude) * v.vertex.xyz);
}
```
